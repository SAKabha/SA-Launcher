## التثبيت

1. افتح [صفحة التنزيل](https://github.com/SAKabha/SA-Launcher/releases/latest) ونزّل الملف **SA-Launcher-Setup-….exe**.
2. شغّله. إذا ظهرت رسالة **«Windows protected your PC»**، اضغط **More info** ثم **Run anyway**. هذه الرسالة تظهر لأي برنامج جديد غير موقّع رقميًا.
3. افتح SA Launcher، واختر البرنامج الذي تريده، واضغط **تثبيت**.

البرامج تُثبَّت لحسابك في Windows فقط، ولا تحتاج صلاحيات المسؤول. يمكنك حذفها من **المكتبة** داخل اللانشر، أو حذف اللانشر نفسه من **إعدادات Windows ← التطبيقات**.

## English

**Install:** download **SA-Launcher-Setup-….exe** from the [releases page](https://github.com/SAKabha/SA-Launcher/releases/latest) and run it. If Windows shows "Windows protected your PC", click *More info*, then *Run anyway*. No administrator rights are needed. No accounts, no tracking. Every download is verified with SHA-256 before it is installed.
